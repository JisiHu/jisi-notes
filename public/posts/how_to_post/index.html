更新博客方法（备忘）

October 23, 2025 · 1 min · Jisi Hu

更新的方法#

进入项目根目录#

打开终端

输入

hugo new posts/文件名.md

在刚刚创建的文件中输入内容#

在本地预览（可不做）#

在刚刚的终端，输入

hugo server -D

先生成生产环境文件（确保 draft: false）#

hugo

写好后，输入这几个指令即可#

git add .
git commit -m "发布新文章" #说明理由就行
git push
